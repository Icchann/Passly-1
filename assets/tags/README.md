# タグのロゴ

タグのステッカーに使うロゴ．

- Flutter・Figma 以外は [Simple Icons](https://github.com/simple-icons/simple-icons)（CC0 1.0）．色は各ブランドの色にしている．
- Flutter・Figma は [Devicon](https://github.com/devicons/devicon)（MIT License）の色つきロゴ．
- ロゴは各社の商標．各社のブランドガイドラインに沿って使う．
- AWS・Azure・C#・VSCode・Adobe XD・Photoshop・Illustrator は Simple Icons にロゴがないので，アプリでは文字のステッカーにしている．
